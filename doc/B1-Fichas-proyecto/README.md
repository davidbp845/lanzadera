# B1 — Fichas de proyecto

Nivel B de la [metodología](../A0-Metodologia/metodologia-de-diseno-y-desarrollo.md). Solo los proyectos **no estándar** tienen ficha: los demás se arrancan con un único `./start.sh` (o `npm run dev`) y se paran matando a quien escucha su puerto, y su fila del registro basta.

Las fichas describen proyectos de cada instalación, así que no están en este repo: viven junto a los datos, en `doc-local/` del contenedor ([ADR-0012](../A2-ADR/0012-lanzadera-sustituye-a-home.md)). Aquí está solo la plantilla: [0-plantilla.md](0-plantilla.md).
